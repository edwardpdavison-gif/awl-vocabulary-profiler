\# AWL Vocabulary Profiler



A web application for teachers that analyses text against Coxhead's Academic Word List (AWL).



\## Features



\- Text tokenisation

\- AWL word-family matching

\- AWL token counts

\- AWL coverage percentage

\- AWL family counts

\- Frequency analysis

\- AWL sublist breakdown

\### Backend
